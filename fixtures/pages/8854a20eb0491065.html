Agentic Coding Benchmarks: A Systematic Evaluation of 12 Systems

We evaluate 12 agentic coding systems on 1,040 repository-level tasks drawn from 60 open-source projects.

The best system completes 41% of tasks end-to-end without human intervention, and median completion across systems is 12%.

Task completion drops sharply for tasks requiring more than three file edits, which account for 58% of the benchmark.

We release the harness, the task set and per-system logs to support replication.
