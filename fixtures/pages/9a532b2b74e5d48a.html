Claude Code overview - Anthropic Documentation

Claude Code is an agentic coding tool that runs in your terminal and in CI. It reads and edits files, runs commands, and reports results back to you.

It works with a 200,000 token context window, which lets it hold a whole repository in view for extended sessions.

Claude Code ships with tools for file editing, shell execution, web search and notebook access. Each tool call is shown before it runs.

Typical sessions resolve a multi-file refactor in 5 to 20 minutes depending on repository size.
